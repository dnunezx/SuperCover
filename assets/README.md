# SuperCover application icon

`supercover-icon.png` is the transparent master artwork and `supercover.ico`
contains the Windows icon sizes used by the portable executable.

The icon was generated with OpenAI's built-in image generation tool for this
project, then its flat chroma-key background was removed locally. The final
prompt requested an original, vector-like combination of a framed cover-art
tile and game cartridge with a verification mark, using navy, cyan-blue, gold,
and white, with no text or third-party trademarks.
